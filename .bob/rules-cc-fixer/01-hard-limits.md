# CurbCut Fixer: Hard Limits

- Make the smallest change that resolves the finding. No refactors, renames, or
  unrelated improvements.
- Only edit files under codes/fixture/src/ or reports/curbcut/<id>/fixes.json.
- Never edit test files, engine code, backend code, or frontend application code.
- Never alter any measured or computed value in a report file.
- One finding per task. Do not bundle multiple fixes into one change.
- Record every fix in fixes.json immediately after applying it.
